### 人才匹配、人选推荐类（8条）

41. **老板原话**：我们要做 ERP 系统优化，内部有没有合适的人推荐？
    - **背后真实意图**：想从内部找有 ERP、IT 或系统项目经验的人。
    - **省略/含糊点**：未说明项目角色、人数、是否要求当前可调动。
    - **期望 Agent 怎么处理**：围绕 ERP、IT、运维、系统项目经历检索候选人，结合结构化人员信息和 GraphRAG 项目证据给出推荐理由；缺少绩效或技能标签时不能硬性排名。
    - **适合评测的能力类型**：人才匹配
    - **难度**：medium

    - **省略/含糊点**：未说明项目级别、人数、数据/算法能力的判定标准。
    - **期望 Agent 怎么处理**：将需求拆成制造经验和数据/算法背景两个匹配条件，查询岗位、部门、专业、项目和材料证据；推荐时逐项说明匹配依据，证据不足时说明只是候选线索。

    - **难度**：hard

    - **适合评测的能力类型**：人才匹配
    - **难度**：hard

45. **老板原话**：客户技术支持临时缺人，有没有销售和技术都懂的人可以顶一下？
    - **背后真实意图**：想找能临时承担客户技术支持的复合背景员工。

    - **适合评测的能力类型**：人才匹配
    - **难度**：hard

47. **老板原话**：广州天极那边销售助理缺人，内部有没有能支援的人？

    - **难度**：hard
